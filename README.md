# Turtle Race Game 🐢🏁

This is my **first GUI project** using Python's `turtle` module.

### 🚀 What It Does:
- Lets you bet on a turtle's color.
- Starts a fun race between colorful turtles.
- Displays the winner and tells if you guessed it right.

### 🎯 Features:
- Graphical user interface (no terminal-based logic).
- Random turtle movement to keep races unpredictable.
- A clear "FINISH" line with vertical labeling.
- Easy to customize with more turtles or colors.

### ✍️ Personal Note:
This is my **first GUI project**, and honestly — it didn’t feel so tough but was **so much fun** to make! 😄  
It gave me confidence to build more visual Python projects.
